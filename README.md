# ovayo
Ovayo Studio Marketing and IT services

Ovayo is a digital-focused company building modern, practical solutions for businesses and brands. This repository contains the source code for the official Ovayo website.

Website

The website is currently built as a lightweight static site using:

* HTML5
* CSS
* JavaScript
* Responsive web design

The current production entry point is:

index.html

Project Structure

ovayo/
├── index.html
└── README.md

The project structure may expand as the website develops.

Local Development

To run the website locally:

1. Clone the repository.
2. Open the project in VS Code.
3. Open index.html directly in your browser or use a local development server such as the VS Code Live Server extension.

Deployment

The website is maintained through GitHub and may be deployed through GitHub Pages or another hosting provider.

Custom domain and production hosting configuration are managed separately from the source code.

Development

Changes should be tested locally before being committed to the main branch.

Typical workflow:

git add .
git commit -m "Describe your changes"
git push origin main
